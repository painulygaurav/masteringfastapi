1. Navigate to your app directory
2. run `python3 -m venv .venv`

   > About `python3 -m venv .venv`: This command creates a Python virtual environment named `.venv` in your current project directory.
   > -m : Run a python module as a program
   > run python's built-in venv module
   > `venv` Python's virtual environment module. A virtual environment gives your project its own isolated Python environment and packages.

3. Activate python virtual environment.
   > source .venv/bin/activate
